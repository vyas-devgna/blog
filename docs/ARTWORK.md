# Original editorial covers

Seven original images were generated with the built-in imagegen tool on 2026-10-04. There was no API-key workflow. Selected PNG masters live in `src/assets/covers/`; the build serves responsive WebP derivatives and uses the same artwork behind readable social-card typography. The page identifies each as AI-generated cover artwork. These images are visual metaphors, not photographs of experiments or scientific evidence.

## Prompt set and subjects

Each prompt requested a finished landscape 3:2 editorial image, tactile material realism, balanced central forms safe for a wide crop, and no words, numbers, logos, screens, people or watermarks.

| Article                   | Prompt subject and direction                                                                                                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent memory              | Translucent vellum pages suspended in a midnight-blue archive, quietly pierced by one persistent red thread; cinematic paper sculpture, fine fibers and projected shadows.                     |
| MCP security              | Seven glass trust-boundary gates across warm stone, with a silver cable passing through their apertures and an amber gate; surreal architectural model photography.                            |
| HERMES                    | A small copper-and-ceramic two-stage mechanism separates flowing blue and amber particles under a faint energy filament; intimate macro still-life on dark slate.                              |
| AI code review            | An intricate ivory paper bridge with a loupe revealing a tiny red structural crack; a metaphor for consequence rather than change volume.                                                      |
| Browser transfer          | Luminous folded-paper parcels travel directly between cobalt glass vessels on separate rocky islands, curving around an obstruction; a metaphor for peers, flow control and network obstacles. |
| Local-first collaboration | Three independent mobiles carry cobalt, coral and cream shapes while their shadows converge into a shared composition; handmade kinetic sculpture in a sage gallery.                           |
| Blog architecture         | An open paper library on stone connects by one thin copper line to a separate blue service chamber; static reading surfaces and a small dynamic backend.                                       |

Compression does not alter the subject or add visual content. The source files remain available for future editions. Hashes in derivative filenames prevent replacement artwork from inheriting an old cached image.
